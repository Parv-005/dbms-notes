11Quick self-test (MCQs)

1. A double ellipse represents

  1. derived attribute
  2. multivalued attribute
  3. composite attribute
  4. key attribute
Answer

(b)

2. A weak entity type always has

  1. partial participation in its identifying relationship
  2. total participation in its identifying relationship
  3. a primary key
  4. no attributes
Answer

(b)

3. Key of a weak entity table =

  1. partial key
  2. owner key
  3. owner key + partial key
  4. a new surrogate key
Answer

(c)

4. Generalization is a … approach

  1. top-down
  2. bottom-up
  3. inside-out
  4. mixed
Answer

(b)

5. A relationship among relationships is expressed using

  1. specialization
  2. generalization
  3. aggregation
  4. weak entity
Answer

(c)

6. Minimum tables for A —(M:N)— B with no attributes on the relationship:

  1. 1
  2. 2
  3. 3
  4. 4
Answer

(c) A, B and the relationship table.

7. Minimum tables for A —(1:N)— B:

  1. 1
  2. 2
  3. 3
  4. 4
Answer

(b) FK of A in B.

8. Minimum tables for A —(1:1, total on both sides)— B:

  1. 1
  2. 2
  3. 3
  4. depends on attributes
Answer

(a) merge into one.

9. In a 1:N relationship, a relationship attribute can be moved to

  1. the 1 side
  2. the N side
  3. either side
  4. neither
Answer

(b)

10. Age computed from date of birth is a … attribute

  1. stored
  2. composite
  3. derived
  4. multivalued
Answer

(c)

11. A person who is both an employee and a student shows a … specialization

  1. disjoint
  2. overlapping
  3. partial
  4. total
Answer

(b)

12. Only-subclass tables (no superclass table) are valid when the specialization is

  1. partial
  2. total
  3. overlapping only
  4. never
Answer

(b) — and preferably disjoint.

13. Role names are essential in

  1. ternary relationships
  2. recursive relationships
  3. weak entities
  4. aggregation
Answer

(b)

14. (min,max) = (0,N) next to DEPARTMENT in WORKS_FOR means

  1. every department has employees
  2. a department may have zero or many employees
  3. each employee is in N departments
  4. at most one employee
Answer

(b)

15. The ER model was proposed by

  1. E. F. Codd
  2. Peter Chen
  3. Charles Bachman
  4. Ullman
Answer

(b) 1976.

16. A relationship type of degree 3 is

  1. unary
  2. binary
  3. ternary
  4. recursive
Answer

(c)

17. Which is NOT mapped to a column?

  1. simple attribute
  2. component of a composite
  3. derived attribute
  4. partial key
Answer

(c)

18. Total participation is shown by

  1. an arrow
  2. a double line
  3. a dashed line
  4. a double ellipse
Answer

(b)

19. A strong entity with a multivalued and a composite attribute, nothing else: tables?

  1. 1
  2. 2
  3. 3
  4. 4
Answer

(b) the composite costs nothing.

20. Primary key of TEACHES(instructor 1, course N, student M)

  1. (instructor, course)
  2. (course, student)
  3. (instructor, student)
  4. all three
Answer

(b) keys of the non-“1” sides.

21. Attribute inheritance means a subclass

  1. loses superclass attributes
  2. gets all superclass attributes and relationships
  3. gets only the key
  4. must be total
Answer

(b)

22. Normalization is an example of

  1. top-down design
  2. bottom-up design
  3. physical design
  4. aggregation
Answer

(b)
