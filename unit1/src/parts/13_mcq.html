13Quick self-test (MCQs)

1. Adding a B+ tree index on Student.Roll without changing any program is an example of

  1. logical data independence
  2. physical data independence
  3. data abstraction at view level
  4. controlled redundancy
Answer

(b) the internal schema changed; the conceptual schema did not.

2. Splitting EMPLOYEE into EMP and EMP_ADDRESS and redefining the old view so programs still work shows

  1. physical data independence
  2. logical data independence
  3. atomicity
  4. integrity independence only
Answer

(b)

3. The level that describes what data is stored in the whole database and the relationships among them is the

  1. physical level
  2. view level
  3. conceptual level
  4. internal level
Answer

(c)

4. The data dictionary stores

  1. user data
  2. metadata
  3. log records only
  4. indexes only
Answer

(b)

5. In the hierarchical model a many-to-many relationship is represented by

  1. a link record with two owners
  2. a separate table of keys
  3. duplicating child records (or virtual records)
  4. it cannot be stored at all
Answer

(c)

6. Which model represents relationships by common attribute values instead of pointers?

  1. hierarchical
  2. network
  3. relational
  4. none
Answer

(c)

7. The component that translates a SQL query into an evaluation plan is the

  1. DDL interpreter
  2. DML compiler
  3. buffer manager
  4. file manager
Answer

(b)

8. Concurrency control and recovery belong to the

  1. transaction manager
  2. DDL interpreter
  3. query evaluation engine
  4. authorization manager
Answer

(a)

9. Two clerks update the same Excel sheet simultaneously and one change is lost. This file-system problem is

  1. data isolation
  2. atomicity problem
  3. concurrent-access anomaly
  4. integrity problem
Answer

(c)

10. A power cut after debiting A but before crediting B illustrates the lack of

  1. atomicity
  2. isolation
  3. security
  4. data independence
Answer

(a)

11. In a 3-tier architecture the business logic runs on the

  1. client
  2. application server
  3. database server
  4. data dictionary
Answer

(b)

12. TRUNCATE belongs to

  1. DML
  2. DDL
  3. DCL
  4. TCL
Answer

(b) it changes storage and is auto-committed.

13. Which is a non-procedural language?

  1. relational algebra
  2. CODASYL DML
  3. tuple relational calculus
  4. DL/I
Answer

(c)

14. The overall design of the database, which rarely changes, is the

  1. instance
  2. schema
  3. view
  4. state
Answer

(b)

15. CODASYL DBTG is associated with the

  1. relational model
  2. hierarchical model
  3. network model
  4. document model
Answer

(c)

16. Which is not a disadvantage of a DBMS?

  1. cost of hardware and software
  2. higher impact of failure
  3. data inconsistency
  4. complexity
Answer

(c) — that is a file-system problem.

17. Friends-of-friends recommendations on a social network fit best in a

  1. key-value store
  2. graph database
  3. column-family store
  4. hierarchical DBMS
Answer

(b)

18. External/conceptual mapping is changed to achieve

  1. physical data independence
  2. logical data independence
  3. durability
  4. normalization
Answer

(b)
