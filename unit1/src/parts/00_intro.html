0How to use these notes

  • Syllabus: Introduction to database systems: overview, file systems vs DBMS, advantages of DBMS, levels of abstraction, data independence, data models and their comparison (hierarchical, network, relational model).
  • How Unit 1 is examined. End-sem Q1 (three 4–5-mark parts, attempt two) and the first one or two questions of every mid-sem (CO1). Since 2024 almost every part is a scenario: “a company / university / hospital uses files or spreadsheets … explain how a DBMS helps”, “recommend a data model for …”, “explain the levels of abstraction for this database”. There are only six question types:
    1. File system → DBMS: problems of files, advantages of a DBMS (section 2, 3).
    2. Levels of abstraction / three-schema architecture, with an example (section 4).
    3. Data independence — physical and logical (section 5).
    4. Compare hierarchical, network, relational; recommend one (section 6).
    5. Structure of a DBMS, 1/2/3-tier architecture, DBA, languages (sections 7, 8).
    6. SQL vs NoSQL for a given application — technically Unit 2, but asked as Q1(c) every year (section 9).
  • How to write a scenario answer (section 10 has the templates): name the concept → explain it in one line → apply it to the given scenario with the scenario’s own nouns → conclude. Examiners give most of the marks for the application, not the definition.
  • Sources used: the course PDF (“DBMS Complete Notes”, Unit-1 chapter pp. 1–41), the handwritten “unit 1 notes fresources” (14 pp.), Korth and Elmasri–Navathe for the standard lists and definitions. Diagrams are drawn fresh for these notes.
