7.1 Aggregate functions

Definition

An aggregate function takes a collection of values (a column of a set of rows) and returns a single value that summarises them. SQL has five standard ones: COUNT, SUM, AVG, MIN, MAX.

Syntax: AGG_FUNCTION([DISTINCT | ALL] expression) — e.g. SELECT AVG(salary) FROM employee WHERE dept_id = 10;

Read this output carefully: 9 rows but only 8 salaries (Neel’s is NULL); AVG = 486000 / 8 = 60750, not 486000 / 9. 3 distinct departments (NULL is not counted). On an empty set, COUNT returns 0 while SUM/AVG/MIN/MAX return NULL.

Rules for aggregates
  • Aggregates cannot be used in WHERE (WHERE salary > AVG(salary) is an error) — use a sub-query or HAVING.
  • Aggregates cannot be nested directly in most systems (MAX(AVG(x))) — use a derived table.
  • If the SELECT list has an aggregate, every other column in it must appear in GROUP BY (next section).

7.2 GROUP BY

GROUP BY col partitions the rows (that survived WHERE) into groups with equal values of col; the aggregates are then computed per group, and the result has one row per group. (RA: _{dept\_id}\gamma_{count(*), sum(salary)}(employee).)

  • The golden rule: every column in SELECT must either be inside an aggregate or be listed in GROUP BY. 7.3 HAVING — conditions on groups

HAVING filters groups after grouping, so it can use aggregates. WHERE filters rows before grouping.

{{sql:a_having}} {{sql:a_where_having}}
WHEREHAVING
filters individual rowsfilters groups
applied before GROUP BYapplied after GROUP BY
cannot contain aggregate functionsusually contains aggregate functions
can be used without GROUP BY (SELECT, UPDATE, DELETE)normally used with GROUP BY (without it, the whole table is one group)
WHERE salary > 50000HAVING AVG(salary) > 50000
Performance tip

A condition that does not involve an aggregate (e.g. city <> 'Delhi') belongs in WHERE, not HAVING: filtering rows early means fewer rows to group.

7.5 ORDER BY with groups

The final result can be sorted by an aggregate or its alias: … GROUP BY dept_id ORDER BY COUNT(*) DESC — “departments, largest first” (PYQ 2025: “AreaName and number of sensors per location, highest first”).
