12One-page Revision Sheet

Relational model
  • Relation = table = set of tuples; attribute = column; domain = allowed atomic values; degree = #columns; cardinality = #rows.
  • Schema (structure) vs instance (current rows).
  • No duplicate tuples; order of rows/columns irrelevant; atomic values.
  • NULL: unknown / not applicable / not yet available / withheld. Test with IS NULL.
  • Super ⊇ candidate (minimal) ⊇ primary (chosen, not NULL); alternate = candidate − primary; FK references PK.
  • #super keys with one key of k attrs among n: 2n−k; two keys: inclusion–exclusion.
Integrity constraints
  • Domain (type, NOT NULL, CHECK, DEFAULT) · Key (PRIMARY KEY, UNIQUE) · Entity (PK ≠ NULL) · Referential (FK = existing PK or NULL).
  • Violations: insert/update child FK, delete/update parent PK.
  • Actions: RESTRICT/NO ACTION (reject) · CASCADE · SET NULL · SET DEFAULT.
  • Column-level vs table-level (composite); ALTER TABLE ADD/DROP CONSTRAINT; checked per statement, or DEFERRED to COMMIT; assertions/triggers for multi-table rules.
Relational algebra
  • Fundamental: σ π ρ ∪ − ×  · derived: ∩ ⋈ ÷  · extended: ⟕⟖⟗ γ.
  • ∪ ∩ − need union-compatibility.
  • ⋈θ = σθ(×); natural join drops duplicate column.
  • ÷ for “all/every”: R ÷ S = πX(R) − πX((πX(R) × S) − R). Project dividend first.
  • Patterns: both→∩ of keys; not→−; only→did − did-other; at least 2→self-join ≠; exactly 1→(≥1) − (≥2); max→all − beaten.
Relational calculus
  • TRC {t | P(t)} — tuple variables; DRC {⟨x1..xn⟩ | P} — domain variables.
  • ∃ with ∧, ∀ with ⇒; ∀x P ≡ ¬∃x ¬P.
  • Safe = result values come from the database/constants.
  • RA ≡ safe TRC ≡ safe DRC (Codd) — relationally complete.
  • RA procedural; RC declarative.
SQL
  • DDL CREATE ALTER DROP TRUNCATE RENAME · DML SELECT INSERT UPDATE DELETE · DCL GRANT REVOKE · TCL COMMIT ROLLBACK SAVEPOINT.
  • Order: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT.
  • WHERE filters rows (no aggregates), HAVING filters groups.
  • COUNT(*) counts rows; other aggregates ignore NULL.
  • Non-aggregated SELECT columns must be in GROUP BY.
  • LIKE: % any string, _ one char. = NULL never true.
Joins & sub-queries
  • Inner (matches) · left/right/full outer (+ unmatched, NULL-padded) · cross (all pairs) · natural (same-named columns) · self (aliases).
  • Right-table filter of a LEFT JOIN goes in ON, not WHERE.
  • Scalar (=), multi-row (IN, ANY, ALL), EXISTS.
  • NOT IN + NULL in sub-query ⇒ no rows; use NOT EXISTS.
  • Correlated = refers to outer row, runs per row (“above own dept average”, “max per dept”).
  • Division in SQL: double NOT EXISTS, or GROUP BY … HAVING COUNT = (SELECT COUNT …).
Triggers
  • ECA: event (INSERT/UPDATE/DELETE, DDL, system) · condition (WHEN) · action.
  • BEFORE (validate/modify NEW) · AFTER (audit, update others) · INSTEAD OF (views).
  • Row-level (FOR EACH ROW, OLD/NEW) vs statement-level.
  • Fired automatically; procedures are called explicitly.
NoSQL
  • “Not only SQL”: key-value (Redis), document (MongoDB), column-family (Cassandra), graph (Neo4j).
  • Flexible schema, horizontal scaling, replication, BASE (basically available, soft state, eventually consistent).
  • CAP: at most 2 of consistency, availability, partition tolerance in a partition.
  • Choose SQL for transactions/integrity, NoSQL for volume/variety/availability — often both.
  • MongoDB = document (collections, flexible fields) · Redis = in-memory key-value (cache, sessions) · Cassandra = distributed wide-column (scale, availability).
  • Limitations: no standard query language, eventual consistency, weak joins/relationships, duplication.

12.2 Two-mark questions

QuestionAnswer
Who proposed the relational model and when?E. F. Codd, IBM, 1970.
Degree and cardinality of R × S if R is 4×3 (rows×cols) and S is 5×2?Degree 3 + 2 = 5; cardinality 4 × 5 = 20.
What is entity integrity?No component of a primary key may be NULL.
Can a foreign key be NULL? Can it repeat?Yes (unless declared NOT NULL); yes.
What is a self-referencing foreign key?An FK that references the PK of its own table, e.g. employee.manager_id → employee.emp_id.
Which operations can violate referential integrity?Insert/update of the child FK, delete/update of the referenced parent PK.
Which RA operators are fundamental?σ, π, ρ, ∪, −, ×.
Express ∩ using −.R ∩ S = R − (R − S).
When are two relations union-compatible?Same number of attributes and corresponding attributes have the same domains.
Which RA operator answers “for all” queries?Division ÷ (in calculus: ∀; in SQL: double NOT EXISTS).
What is the result schema of R(A,B,C) ÷ S(B,C)?(A).
What is a safe expression?A calculus expression whose result contains only values from the database or the expression — hence finite.
What is relational completeness?Ability to express every query expressible in relational algebra.
Free vs bound variable?Bound = introduced by ∃/∀; free = not bound (only the result variable may be free).
Why does WHERE x = NULL return nothing?Comparison with NULL is UNKNOWN, and WHERE keeps only TRUE rows; use IS NULL.
Can WHERE contain an aggregate?No — WHERE runs before grouping; use HAVING or a sub-query.
AVG of (10, NULL, 20)?15 (NULL ignored).
What does COUNT(DISTINCT dept) count?Number of different non-NULL dept values.
Name the four referential actions.RESTRICT/NO ACTION, CASCADE, SET NULL, SET DEFAULT.
Is TRUNCATE DDL or DML?DDL (removes all rows, keeps structure, auto-commit in Oracle/MySQL).
What is a derived table?A sub-query in the FROM clause, given an alias.
What does > ALL (sub) mean?Greater than every value returned = greater than the maximum.
What are OLD and NEW in a trigger?Row values before and after the change (UPDATE has both, INSERT only NEW, DELETE only OLD).
What is an INSTEAD OF trigger?A trigger on a view that runs in place of the INSERT/UPDATE/DELETE issued on the view.
Expand NoSQL and BASE.Not only SQL; Basically Available, Soft state, Eventually consistent.
State the CAP theorem.A distributed system cannot simultaneously guarantee consistency, availability and partition tolerance; during a partition it must give up C or A.
Which NoSQL type for a social network’s friend graph? For shopping carts?Graph database; key-value store.
Why is Redis fast? Give two uses.It keeps data in memory (RAM); caching and user sessions (also gaming, real-time apps).
What is a collection in MongoDB?A group of related documents (like a table, but documents can have different fields).
Name four limitations of NoSQL.Lack of standardisation, eventual consistency, complex relationships/joins, data duplication.

13Quick Self-Test (MCQs)

1. A relation with 5 attributes and 8 tuples has degree

  1. 8
  2. 5
  3. 40
  4. 13
Answer

(b) 5 — degree counts attributes.

2. Which is always true?

  1. every super key is a candidate key
  2. every candidate key is a primary key
  3. every primary key is a super key
  4. a relation has one candidate key
Answer

(c)

3. R(A,B,C,D) has the single candidate key {A,B}. Number of super keys?

  1. 2
  2. 4
  3. 8
  4. 16
Answer

(b) 24−2 = 4.

4. Entity integrity states that

  1. FK values must exist in the parent
  2. PK attributes cannot be NULL
  3. values must be atomic
  4. no duplicate columns
Answer

(b)

5. Deleting a parent row whose FK children are declared ON DELETE SET NULL

  1. is rejected
  2. deletes the children
  3. sets the children’s FK to NULL
  4. sets the parent PK to NULL
Answer

(c)

6. Which RA operator is NOT fundamental?

  1. −
  2. ×
  3. ρ
  4. ⋈
Answer

(d) join = σ(×).

7. |R| = 3, |S| = 4. |R × S| = ?

  1. 7
  2. 12
  3. ≤ 12
  4. 1
Answer

(b) exactly 12.

8. R(A,B) ÷ S(B) returns

  1. A-values paired with some B of S
  2. A-values paired with every B of S
  3. B-values in both
  4. R − S
Answer

(b)

9. Union-compatibility is NOT required for

  1. ∪
  2. ∩
  3. −
  4. ×
Answer

(d)

10. π removes

  1. rows failing a condition
  2. duplicate tuples
  3. NULLs
  4. nothing
Answer

(b) — it keeps chosen columns and eliminates duplicates.

11. Relational calculus is

  1. procedural
  2. non-procedural
  3. a programming language
  4. a storage structure

(b)

12. ∀x P(x) is equivalent to

  1. ∃x P(x)
  2. ¬∃x ¬P(x)
  3. ¬∀x ¬P(x)
  4. ∃x ¬P(x)

(b)

13. {t | ¬(t ∈ Student)} is

  1. safe
  2. unsafe
  3. empty
  4. equal to Student

14. Which is DDL?

  1. UPDATE
  2. TRUNCATE

  4. 2, 4

(b)

16. Which clause can contain an aggregate condition?

  1. WHERE
  2. FROM
  3. HAVING
  4. ON

(c)

17. name LIKE '_a%' matches

  1. names ending with a
  2. names whose second letter is a
  3. names starting with a
  4. names containing exactly one a

(b)

18. WHERE id NOT IN (1, 2, NULL) returns

  1. ids other than 1, 2
  2. no rows
  3. all rows
  4. an error

(b) — the NULL makes every comparison UNKNOWN.
