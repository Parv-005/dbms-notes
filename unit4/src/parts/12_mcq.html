12Quick self-test (MCQs)

1. Which FD is trivial?

  1. A → B
  2. AB → A
  3. A → AB
  4. AB → C
Answer

(b) RHS ⊆ LHS.

2. X → Y and WY → Z ⊢ WX → Z is called

  1. augmentation
  2. union
  3. pseudo-transitivity
  4. decomposition
Answer

(c)

3. R(ABCD), F = {A → B, B → C, C → D}. Number of superkeys?

  1. 1
  2. 4
  3. 8
  4. 15
Answer

(c) only key A → 23 = 8.

4. Armstrong’s axioms are

  1. sound but not complete
  2. complete but not sound
  3. sound and complete
  4. neither
Answer

(c)

5. For F = {A → B, B → C, CD → E}, A+ =

  1. AB
  2. ABC
  3. ABCE
  4. ABCDE
Answer

(b) CD → E needs D.

6. 2NF removes

  1. multivalued attributes
  2. partial dependencies
  3. transitive dependencies
  4. all FDs with non-key LHS
Answer

(b)

7. R(ABCD), F = {AB → C, C → D}. Highest NF?

  1. 1NF
  2. 2NF
  3. 3NF
  4. BCNF
Answer

(b) key AB; C → D is transitive, no partial dependency.

8. R(ABC), F = {AB → C, C → A}. Highest NF?

  1. 1NF
  2. 2NF
  3. 3NF
  4. BCNF
Answer

(c) keys AB, BC; C → A has prime RHS but C is not a superkey.

9. Every relation with exactly two attributes is in

  1. 1NF only
  2. 2NF only
  3. 3NF only
  4. BCNF
Answer

(d)

10. A 3NF relation that is not in BCNF has an FD X → A where

  1. X is a superkey
  2. A is non-prime
  3. X is not a superkey and A is prime
  4. X ∩ A ≠ ∅
Answer

(c)

11. R → R1, R2 is lossless if

  1. R1 ∩ R2 = ∅
  2. R1 ∩ R2 → R1 or R1 ∩ R2 → R2
  3. R1 → R2
  4. R1 ∪ R2 ⊂ R
Answer

(b)

12. Spurious tuples are produced by

  1. a lossy decomposition
  2. a dependency-preserving decomposition
  3. NULL values
  4. BCNF
Answer

(a)

13. Which is always both lossless and dependency preserving?

  1. BCNF decomposition
  2. 3NF synthesis
  3. any 2NF split
  4. none
Answer

(b)

14. Minimal cover of {A → B, B → C, A → C}

  1. {A → B, B → C}
  2. {A → C}
  3. {A → BC}
  4. unchanged
Answer

(a) A → C is redundant.

15. If every candidate key has one attribute, the relation is at least in

  1. 1NF
  2. 2NF
  3. 3NF
  4. BCNF
Answer

(b)

16. An FD that holds in one table state

  1. holds forever
  2. may or may not be an FD of the schema
  3. is trivial
  4. is a key
Answer

(b)

17. Deleting the last student of a course also loses the course details. This is

  1. insertion anomaly
  2. update anomaly
  3. deletion anomaly
  4. spurious tuple
Answer

(c)

18. A prime attribute is one that

  1. is in the primary key only
  2. is in some candidate key
  3. is in every candidate key
  4. determines all attributes
Answer

(b)
