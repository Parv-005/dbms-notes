Practice P5inference rules5 × 1 mark

Prove using Armstrong’s axioms, or disprove with a counterexample: (a) {A → B, C → D} ⊢ AC → BD  (b) {AB → C} ⊢ A → C  (c) {A → B, BC → D} ⊢ AC → D  (d) {A → B, C → B} ⊢ A → C  (e) {AB → C, C → A} ⊢ C → B

Show answer
  1. True. A → B ⇒ AC → BC (augment by C); C → D ⇒ BC → BD (augment by B); transitivity ⇒ AC → BD.
  2. False. Rows (a1, b1, c1), (a1, b2, c2): AB → C holds, A → C fails.
  3. True. Pseudo-transitivity with W = C: A → B and CB → D ⇒ CA → D. (Or: A → B ⇒ AC → BC; BC → D; transitivity.)
  4. False. Rows (a1, b1, c1), (a1, b1, c2) over (A, B, C): A → B and C → B hold, A → C fails.
  5. False. C+ = {C, A} ∌ B. Counterexample over (A, B, C): rows (a1, b1, c1) and (a1, b2, c1). AB → C holds (the AB values differ), C → A holds (same A), but C → B fails (b1 ≠ b2).

Fast check for any of these: compute the closure of the LHS under the given FDs. (a) (AC)+ = ABCD ✔ (b) A+ = A ✗ (c) (AC)+ = ABCD ✔ (d) A+ = AB ✗ (e) C+ = AC ✗.

Practice P6minimal cover is not unique4 marks

F = {A → BC, B → AC, C → AB}. Find two different minimal covers of F and prove both are equivalent to F. Must all minimal covers have the same number of FDs?

Show answer

Split: A → B, A → C, B → A, B → C, C → A, C → B. All LHSs are single attributes (nothing extraneous). Now remove redundant FDs — the result depends on the order:

  • Remove A → C (A → B → C), then B → A (B → C → A), then C → B (C → A → B): G1 = {A → B, B → C, C → A} (a cycle).
  • Remove A → B (A → C → B), then B → A (B → C → A): left with A → C, B → C, C → A, C → B; none of these is redundant any more → G2 = {A → C, B → C, C → A, C → B}.

Equivalence: in G1, A+ = B+ = C+ = ABC; in G2, C+ = ABC, A+ = ACB, B+ = BCA. In F every single attribute also has closure ABC. So each set implies every FD of the others → G1 ≡ G2 ≡ F.

Two valid minimal covers with 3 and 4 FDs — minimal covers are not unique and need not even have the same size.

Practice P8proof question3 marks

Show that R(S, C, T) with F = {S C → T, T → C} has no BCNF decomposition that is both lossless and dependency preserving.

Show answer

Keys: SC and ST (T → C, so ST → C). T → C violates BCNF, so R must be split. Any proper decomposition puts the three attributes into relations of at most two attributes each. The FD SC → T needs S, C and T together; in no two-attribute relation can it be checked, and the projections of F on two-attribute relations are only T → C (on TC) or trivial FDs, which do not imply SC → T. So SC → T is lost in every BCNF decomposition. Lossless ones exist (TC + ST), but none preserves SC → T.

This is the Teach(Student, Course, Teacher) example of section 7 — the reason the 3NF definition has the “A is prime” escape clause.

Last-day checklist for a normalization question
  1. List all candidate keys (never-on-RHS attributes first) and write prime / non-prime.
  2. For “highest NF”, name the exact FD that breaks the next NF, and say why (part of key / not a key / RHS non-prime).
  3. For 3NF use synthesis from a minimal cover; add a key relation if needed; say “lossless and dependency preserving”.
  4. For BCNF split on a violating FD, recheck the new relations, then test dependency preservation.
  5. For “lossless?”: two relations → intersection closure; three or more → merge pairs or chase. Never intersect all at once.
  6. Underline the key of every final relation.
